# Agent Directives & Project Rules

## Project Scope
- Application: To-Do List with integrated Notes and a Priority Filter feature.
- Deliverable: Responsive web app using HTML, Tailwind CSS, and modular JavaScript.

## Coding Standards
- Clean, semantic HTML and vanilla JavaScript.
- Modern responsive layout using Tailwind CSS CDN.
- Fully functional LocalStorage persistence for tasks and notes.
- Graceful empty states and input validation.

## Testing & Validation Requirements
- Include standalone automated unit tests for core operations: task CRUD, completion toggle, priority filtering, and note management.
- Validate that all edge cases (empty inputs, whitespace, duplicate IDs) pass cleanly.
